# Federal Judges Clerkship Guide

A searchable web guide to **federal judges** (circuit and district level) in the
United States. For each judge it shows:

1. **Courthouse location** — duty station, court, and lat/lng for mapping.
2. **Clerk-relevant background** — appointment, party, years on the bench,
   education, and a Wikipedia biography.
3. **Hiring status** — whether the judge is currently hiring clerks on
   [OSCAR](https://oscar.uscourts.gov), the position term, and posting freshness.

The data is produced by a Python pipeline that scrapes Wikipedia judge lists,
geocodes duty stations, enriches bios, and parses OSCAR clerkship postings. The
static site under [`app/`](app/) consumes a generated `app/judges.json`.

## Quick start

```sh
# 1. Create the environment
python3 -m venv .venv
./.venv/bin/python -m pip install -e ".[dev]"

# 2. Run the full pipeline (scrapes Wikipedia, geocodes, parses OSCAR, builds map + site data)
./.venv/bin/python run_pipeline.py

# 3. Preview the web page locally
cd app && python -m http.server 8000   # then open http://localhost:8000
```

To re-run without re-scraping Wikipedia (uses the committed CSVs):

```sh
./.venv/bin/python run_pipeline.py --skip-scrape
```

## Pipeline stages

| Step | Script | Output |
|------|--------|--------|
| 1. Scrape current circuit judges | `current_circuit_judges.py` | `current_circuit_judges.csv` |
| 2. Scrape current district judges | `current_district_judges.py` | `current_district_judges.csv` |
| 3. Scrape presidential appointees | `pres_appoints.py` | `pres_appeals.csv`, `pres_district.csv` |
| 4. Merge + incumbent filter | `merge.py` | `active_*.csv` |
| 5. Geocode duty stations | `add_info.py` | `final_*.csv` |
| 6. Enrich bios (Wikipedia) | `enrich_judges.py` | `final_*_enriched.csv` |
| 7. Build interactive map | `make_map.py` | `oscar_clerkship_map.html` |
| 8. Export site data | `export_site_data.py` | `app/judges.json` |
| 9. Validate | `run_pipeline.py` | console report |

## Web page (`app/`)

- `index.html` / `styles.css` — layout, responsive, dark-mode friendly.
- `app.js` — loads `judges.json`, live search by judge/court/city, filter by
  hiring status and court level, and a detail panel with all clerk-relevant facts.
- `judges.json` — generated by `export_site_data.py` (git-ignored; regenerated by
  the pipeline).

## Deployment

A GitHub Actions workflow ([`.github/workflows/pages.yml`](.github/workflows/pages.yml))
runs the pipeline (in `--skip-scrape` mode) and deploys `app/` to **GitHub Pages**
on every push to `main`. The interactive Folium map is also published at
`/map.html`.

## Known data limitations

- **Geocoding coverage** is ~86% for district and ~97% for circuit. The gap is
  almost entirely senior/inactive judges whose Wikipedia entry lists no current
  duty station (`inactive` / `none`).
- **Hiring match**: OSCAR lists ~81 clerkships, but ~46 of those judges are not in
  the current Wikipedia incumbent list (magistrate/bankruptcy judges, or name
  variants). The matcher uses normalized full name then a unique first+last
  fallback; the 36 matched hires are accurate.
- **Term length** is recorded in OSCAR for only ~30 of 81 listings; the rest show
  `N/A` because the source row omits it.
